# 取引一覧のローカル試作

アプリの起動後に `http://localhost:8080/transactions` または `http://localhost:8080/` を開くと一覧が表示されます。

表示項目は写真、商品名、価格、送料、利益、取引プラットフォームです。販売日が新しい順に並びます。同じ販売日の場合は取引番号が大きい順です。

## データの準備

`database/transactions.sql` は `cashflow` 内に `users` と `transactions` を作成するSQL（データベースへの命令）です。既存の `marker` は変更しません。別の環境に移した際は、MySQLの操作画面でこのSQLを実行してください。

商品データは `transactions` に保存します。一覧の「取引を新規登録」から登録できます。直接開く場合は `http://localhost:8080/transactions/new` です。データが0件なら「取引はまだありません」と表示します。編集画面は未実装です。

| 画面 | データベースの項目 |
| --- | --- |
| 写真 | image_path |
| 商品名 | item_name |
| 価格 | selling_price |
| 送料 | shipping_cost |
| 利益 | Javaで selling_price − shipping_cost − purchase_price を計算 |
| 取引プラットフォーム | marketplace。「その他」の場合はcustom_marketplace |

金額は円です。仕入価格が未設定の場合は0円として計算します。保存済みのprofitではなく、各金額から再計算した利益を表示します。

写真は登録画面からJPEG・PNGを1枚、5MB以下・2,000万画素以下で選択できます。写真は任意です。保存時にPNGに変換し、作業フォルダ内の `uploads/images/` に保存します。このフォルダもDBと一緒にバックアップしてください。DBには写真の表示先だけを保存します。

## 新規登録の仕様（今回のユーザー指定を優先）

- 商品名・価格・送料・取引プラットフォームは必須です。
- 仕入れ価格は任意で、未入力は0円です。金額は0〜1,000,000,000円の整数に対応します。
- プラットフォームはメルカリ・ヤフーオークション・ラクマ・その他です。「その他」の名前も任意です。
- 利益は「価格 − 送料 − 仕入れ価格」です。販売手数料は差し引きません。既存取引の一覧もこの計算に統一します。
- 画面で利益を即時表示し、保存時にはJava側で再計算します。販売手数料率と販売手数料には0を保存します。
- 販売日の入力欄は設けず、登録した日を保存します。
- 登録成功後は一覧に戻ります。入力ミスの場合は内容を保持しますが、写真は再選択が必要です。容量超過の場合は入力画面から再入力します。
- この変更は元の設計書の手数料控除・プラットフォーム選択肢・その他名称必須の仕様に優先します。

## 試作の範囲

ユーザーの指定により、ログインなしで全取引を表示します。同じPCからのみアクセスするため `server.address=127.0.0.1` を設定しています。

設計書のユーザー別表示はまだ実装していません。公開する前にユーザー登録・ログインを実装し、既存取引のuser_id（所有者の番号）を設定して必須にし、取得条件をログインユーザーに限定する必要があります。
